## 🎮 About Project Hestia

**Project Hestia** is a Fortnite OG emulator project built around the classic Fortnite experience. With a focus on legacy emulation, game preservation, and dedicated launcher development, Hestia aims to bring enthusiasts closer to the era that made Fortnite memorable.

The project explores the technical challenges of legacy game compatibility while providing a central place for project information, launcher access, and development updates.

Whether you're interested in classic Fortnite, legacy game builds, or emulation technology, Project Hestia is dedicated to exploring and preserving the history of Fortnite.

Some experiences never get old. **Project Hestia is built around keeping the spirit of the OG era alive.**
